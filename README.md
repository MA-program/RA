Es un sitio web desarrollado para presentar un Sistema de Gestión de Inventarios Tecnológicos. El proyecto fue elaborado utilizando HTML, CSS y JavaScript, aplicando además el uso de Git y GitHub para el control de versiones.

Objetivo:

Desarrollar un sitio web informativo que permita mostrar las funcionalidades y beneficios de un sistema de gestión de inventarios tecnológicos.

Tecnologías utilizadas
HTML
CSS3
JavaScript
Git
GitHub

Funcionalidades:
    Menú de navegación.
    Diseño responsivo.
    Sección informativa.
    Formulario de contacto.
    Validaciones mediante JavaScript.
    Control de versiones con Git.
